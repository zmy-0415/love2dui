# 《裂界》M2 — 从「一把更强的剑」到「一套能刷的装备」

M1 结束时，游戏的核心循环是闭合的：挖矿 → 造装备 → 打怪 → 打 Boss。
但装备这一环其实是假的——四条配方，全是剑，一条比一条伤害高。
玩家没有选择，只有升级。**这不叫装备系统，叫一条经验条。**

M2 只解决这一件事：让「刷装备」成立。

---

## 1. 问题是什么

M1 的武器是一个标量：

```
伤害 = 13 × 材质系数
```

它有两个致命后果：

1. **没有取舍。** 铁剑的伤害永远比铜剑高，铁斧比铁剑高，晶刃比铁斧高。
   玩家不需要判断，只需要按顺序捡。
2. **没有身份。** 两把铁剑完全一样。打到第二把时玩家不会弯腰。

真正能让玩家反复刷的东西，必须**不可比较**。「长枪射程 56 但贴身打不到」
和「战锤击退 270 但后摇 0.32 秒」之间没有大小关系——只有适合与不适合。
一旦武器之间不可比较，玩家就会开始**收集**而不是**升级**。

所以 M2 把武器从一个数拆成四个维度：

```
武器 = 品类（怎么打） × 刃材（打多重） × 柄（打多快） × 芯（打中之后怎样） + 词条
```

---

## 2. 四个维度分别改变什么

### 2.1 品类：判定框的形状就是玩法

八种品类不是八组数值，是**八种「打得到哪」和「出刀时能不能动」**。

| 品类 | 判定框（后延~前伸 × 半高） | 总时长 | 出刀机动 | 群体衰减 | 定位 |
|---|---|---|---|---|---|
| 匕首 | 4 ~ 24 × 16 | 0.200s | 0.72 | 0.90 | 唯一能边跑边打的 |
| 剑   | 6 ~ 34 × 22 | 0.355s | 0.35 | 0.88 | 全能，默认答案 |
| 镰刀 | 10 ~ 36 × 26 | 0.460s | 0.40 | **1.00** | 唯一不衰减的群体武器 |
| 长枪 | **-2** ~ 56 × 12 | 0.350s | 0.45 | 0.92 | 射程最长，**贴身打不到** |
| 战斧 | 4 ~ 30 × 28 | 0.520s | 0.30 | 0.82 | 破韧最高 |
| 大剑 | 4 ~ 40 × 30 | 0.575s | 0.25 | 0.80 | 宽判定，被围住时开缺口 |
| 战锤 | 2 ~ 32 × 31 | 0.650s | 0.20 | 0.78 | 击退 270，空了很亏 |
| 弓   | 远程 520 | 0.400s | 0.85 | — | 唯一远程，箭会被地形吃掉 |

三处刻意的设计：

- **长枪的 `back = -2`。** 判定框从身体外侧 2 像素才开始。这是全表唯一
  「离得越近越打不中」的武器。它让玩家必须维持距离，而维持距离在有冲撞怪的
  游戏里是个真实的操作负担。作为交换，它的前摇后摇都短，是唯一能安全拆
  Boss 尾节弱点的近战。
- **镰刀的 `falloff = 1.00`。** 打三只和打一只，单体伤害完全一样。
  其余武器从第二个目标开始按 0.78~0.92 衰减。这让「被虫群围住」这个状态
  有一个明确的解法，而不是单纯的折磨。
- **战锤的 `mobility = 0.20`。** 出刀瞬间横向速度只剩两成——等于把自己钉住。
  高击退是它的回报，但玩家得先接受「这一下空了就要挨打」。

### 2.2 刃材：唯一决定「打多重」

五种刃材（木 0.72 / 铜 1.00 / 铁 1.38 / 晶 1.82 / 虚空 2.40）只乘伤害与破韧。
刃材靠挖矿换，所以挖矿这条线仍然是「变强」的主干。

### 2.3 柄：唯一决定「打多快」

四种柄（木 / 骨 / 铁 / 虚空）只改前后摇、击退、射程 ±2 像素。

**柄刻意几乎不加伤害（1.00~1.20）。** 如果柄也加伤害，玩家会直接把
「伤害 + 速度」加总成一个数，然后照着总数选——四条线立刻退化回一条。

骨柄（前摇 ×0.90、后摇 ×0.92、击退 ×0.86）和铁柄（前摇 ×1.06、
后摇 ×1.10、击退 ×1.30、破韧 ×1.20）是一对反向取舍，没有谁更好。

### 2.4 芯：唯一决定「打中之后怎样」

五种芯**完全不加伤害**，只换元素状态：

| 芯 | 状态 | 效果 | 解决的问题 |
|---|---|---|---|
| 无芯 | — | — | 便宜、可靠、没有意外 |
| 炎芯 | 燃烧 | 3 秒内约 9 点持续伤害，**可致死** | 磨高血量目标 |
| 霜芯 | 霜蚀 | 移速降到 55%，2.2 秒 | 处理贴脸的快怪 |
| 毒芯 | 剧毒 | 4 秒持续掉血，**不致死（留 1 血）** | 压血线，收尾交给玩家 |
| 雷芯 | 雷痕 | 下一次受击 +30%，然后消失 | 奖励节奏，惩罚乱砍 |

「毒不致死」是这一格里最要紧的设计。如果毒能杀人，玩家就会砍一刀然后跑开
等——战斗变成一个计时器。留 1 血意味着最后一下必须自己打出来。
这条规则有断言守着（`剧毒不致死` / `补一刀才能杀死`）。

## 3. 词条：让同一把铁剑有身份

12 条词条，按权重抽取，**同一个种子得到同一组**（存档只存 spec，
读档后重新解析）。三条约束写死在 `game/core/affix.lua` 的注释里：

1. **必须可感知。** 数值都开到 12%~25%。「+3% 伤害」在 16px 画面里等于没有。
2. **不能互相吃掉。** 伤害类只留 2 条（锋利 +18% / 残忍 对硬直 +25%），
   其余分别管速度、范围、续航、元素、暴击。否则五条词条实际是一条。
3. **随机必须可复现。** 不碰 `math.random`，用种子驱动。

词条位数由**投入档位**决定（刃档 + 柄档 + 芯档）：

```
铜刃(1)+木柄(1)+无芯(0) = 2   → 0 条   开局别指望词条
铁刃(2)+骨柄(2)+无芯(0) = 4   → 1 条   第一次「值得留」的武器
虚空(4)+虚空(5)+雷芯(2) = 11 → 2 条   后期刷词条的区间
```

这条规则让「重铸」在后期才有意义：早期武器没有词条位，玩家不会把材料
浪费在反复重铸铜剑上，而是先去挖铁。

**重铸用的是同一个接口**（`game:forge(spec)`）。玩家想刷就再点一次，
材料够就行。刻意不做「洗练石」之类的中间货币——多一层货币只会让
「我再试一次」这个动作多一次犹豫。

## 4. 精英词缀：五条都改打法，没有一条改数值

| 词缀 | 倍率 | 行为 | 逼玩家改什么 |
|---|---|---|---|
| 爆裂 | 血 ×2.2 | 死亡时炸一圈（半径 74） | 补刀顺序：砍死它的瞬间要后撤 |
| 迅捷 | 血 ×1.5 | 移速 ×1.55、追击 ×1.25 | 追不上，只能提前站位或用霜蚀 |
| 铁壁 | 血 ×2.0 | 韧性 ×2.6、击退只剩 35% | 剑砍不出硬直，必须换斧/锤 |
| 再生 | 血 ×1.8 | 每秒回 2% 最大血 | 打不快就白打，放弃消耗战 |
| 分裂 | 血 ×1.6 | 死亡时变两只小的（血量 35%） | 单体武器打不完，只能换镰刀 |

五条里没有一条是「+20% 血量」。那种词缀玩家看不出来，只会觉得「这只怎么
特别肉」，然后开始怀疑数值而不是调整打法。

## 5. 这一轮修掉的坑

都是「测试全绿但画面不对」或者「逻辑对但玩家会误解」那类：

- **DoT 杀死的怪不掉东西。** 死亡逻辑原本只写在 `onHit` 里，而被点燃的怪
  可能在自己那一帧烧死，根本不经过 `onHit`。现在死亡统一走 `onMobDeath`，
  `deathHandled` 标志防止每帧重复掉落。
- **`updateMobs` 边遍历边追加会丢怪。** 分裂产生的两只小怪是在循环中
  `self.mobs[#self.mobs+1]` 加进去的，而循环结束后用 `keep` 重建列表——
  新怪直接消失。现在先处理旧的一批，结束后再把新生的接回来。
- **易伤写在攻击方而不是目标身上。** 雷痕原本在 `Combat` 里判定，于是
  「雷芯配精英爆炸」不生效。挪到 `Mob:hurt` 之后，所有伤害来源都吃加成。
- **血条用碰撞盒高度定位。** 精英放大 1.3 倍之后血条压在头上。改成
  `m.h * m.scale * 1.15 + 12`，任何体型的怪都刚好在头顶上方。
- **武器按 1:1 画。** 角色只有 24px 高，「长枪」和「匕首」在屏幕上差不到
  6 像素，玩家看不出换了什么。新增 `opts.weaponScale`，玩家手持时放大 1.45。
- **状态叠加会变成四倍伤害。** 现在层数取较大值、时间取较长值（刷新而非累加）。

## 6. 怎么玩

```bash
"C:\workspace\love2dsrc\build\love.exe" . rift
```

| 键 | 作用 |
|---|---|
| A / D、← / → | 移动 |
| 空格 | 跳跃（按住更高） |
| 鼠标左键 | 指方块=挖掘；指空气=朝面朝方向挥砍（按住连击）；弓朝鼠标射 |
| 鼠标右键 | 放置方块 |
| **F** | **锻造台**（选刃材 / 品类 / 柄 / 芯，右侧实时预览） |
| C | 合成台（消耗品） |
| R | 重开 |
| Esc | 关闭弹窗 |

无显卡环境下出图：

```bash
luajit tools/gameshot.lua out.bmp surface   # 地表开局
luajit tools/gameshot.lua out.bmp combat    # 元素状态 + 多目标 + 弓
luajit tools/gameshot.lua out.bmp boss      # 石喉阶段 3
luajit tools/artsheet.lua sheet.bmp 2       # 素材图鉴（八品类武器）
```

## 7. 验证

```
luajit tests/full.lua      560 通过（其中游戏核心 173 条）
luajit tests/examples.lua   74 通过
luajit tests/headless.lua   11 通过
luajit tests/fuzz_layout.lua 120 步无异常
luajit tests/bench.lua      4.17x
```

M2 新增的断言全部落在「组合真的改变行为」上，而不是数值大小：

- 长枪 `back < 0`（贴身打不到）、镰刀 `falloff >= 1`、弓 `reach == 0` 且 `ranged > 0`
- 换柄不改射程与品类；芯不改伤害；同 spec 两次解析结果一致
- 同种子滚出同样词条、词条不重复、不同种子会滚出不同词条
- 锋利 +18% 精确成立；引燃对无芯武器附燃烧、对已有元素的武器升一层
- 燃烧会致死、剧毒停在 1 血、霜蚀减速、雷痕一次性
- 镰刀三个目标伤害相同；大剑第三个目标低于第一个的 75%
- 铁壁韧性 ×2.6 且击退更小；小怪不会二次分裂
- 锻造失败不扣材料；中档组合恰好 1 条词条；同 seed 词条完全一致
- 读档能恢复刃材 / 品类 / 柄 / 芯 / 词条 / 锻造计数，且解析出的数值一致

## 8. 已知问题 / 下一步

- **弓的箭会被一格薄墙吃掉。** 目前是「点 vs 矩形外扩 4px」判定，墙的判定
  用的是同一个 `solidAtPixel`，所以贴着墙射基本必中墙。需要给箭加「贴墙
  擦边」的容错，或者做穿透射击。
- **八品类的平衡只按数值推过，没有手感验证。** 出刀机动、后摇这些参数
  在无显卡环境里只能靠推算。这一版最需要的反馈是「按下去爽不爽」。
- **M3 候选**：护甲槽（让「打怪掉装备」成立）、地形对移动的影响（水/冰/藤蔓）、
  第二个 Boss（会跑的那种，和石喉的「站桩 + 阶段」形成对照）。
